# Contributing Guidelines

Thank you for participating in the IBM Bob AI Innovation Hackathon!

## Guidelines for Submission

1. Ensure all code modifications are inside `src/` or `app.py`.
2. Keep `submission.yaml` completely filled out without missing fields.
3. Test all setup instructions in `docs/setup-guide.md` before pushing to main.
4. Ensure `.env` is listed in `.gitignore` and never committed to the public repository.
